# Новость или фейк?

Статическая веб-игра на русском языке: игрок читает заголовок и выбирает, реальная это мировая новость или фейк. Реальные заголовки ежедневно загружаются из BBC Russian RSS через открытый JSON-прокси rss2json, а фейки генерируются на основе похожих новостных формулировок. До ответа описания у реальных и фейковых карточек нейтральные и не содержат активных ссылок.

## Как открыть локально

```bash
python3 -m http.server 8000
```

После запуска откройте тестовую ссылку. Для ежедневного обновления новостей нужен доступ браузера к интернету:

<http://127.0.0.1:8000/index.html>

## Быстрая проверка

```bash
node --check script.js
curl -I http://127.0.0.1:8000/index.html
```
