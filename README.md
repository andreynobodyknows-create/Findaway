# Новость или фейк?

Статическая браузерная мини-игра для тренировки медиаграмотности. Игрок определяет, взят ли заголовок из новостной ленты или сгенерирован внутри приложения, а после ответа получает пояснение и ссылку на первоисточник.

## Возможности

- ровно 10 раундов: 5 заголовков из RSS и 5 сгенерированных;
- короткие варианты ответа «правда» и «фейк»;
- объединение семи русскоязычных RSS/RDF-лент: BBC, ТАСС, Интерфакс,
  Коммерсантъ, РБК, Новости ООН и Deutsche Welle;
- сбалансированный выбор реальных заголовков: при достаточном числе доступных
  лент каждый реальный раунд использует отдельный источник;
- независимая загрузка источников через `rss2json` с резервным AllOrigins:
  отказ одной ленты не останавливает игру;
- явно обозначенный демонстрационный набор, если внешние сервисы недоступны;
- создание учебных подмен на основе текущих заголовков: изменение решения,
  направления динамики или процента с показом оригинала и конкретной подмены после ответа;
- резервные короткие сценарии из разных областей, если подходящих заголовков для подмены мало;
- сохранение последних 100 фейковых заголовков между перезагрузками через localStorage
  и приоритет сюжетов, которых не было среди последних 10 фейков;
- корректная обработка RSS-дат, повторов и небезопасных URL;
- адаптивный интерфейс, управление с клавиатуры и поддержка экранных дикторов;
- ссылки на исходные публикации после ответа.

Понятие «из новостной ленты» означает происхождение заголовка, а не независимое подтверждение всех фактов в публикации. Значимые утверждения следует сверять по нескольким источникам.

Генерация работает локально, без языковой модели или API-ключа. Это алгоритмические
изменения свежих заголовков и сочетания совместимых деталей резервных сценариев,
а не неограниченное сочинение новых сюжетов. Исходник изменённого заголовка не
показывается как реальный раунд в той же партии. Совпадения с заголовками полученной
ленты исключаются. Учебная подмена не является доказательством ложности события.
При недоступном localStorage история действует только до закрытия или перезагрузки
страницы. Старые сюжеты со временем могут возвращаться с другими деталями.

## Локальный запуск

```bash
python3 -m http.server 8000
```

Откройте <http://127.0.0.1:8000/index.html>.

## Проверка

```bash
npm test
```

Тесты проверяют синтаксис, регрессию прежнего падения генератора, формирование
10 уникальных раундов, разнообразие источников, свежую генерацию фейковых
заголовков, обработку дат и фильтрацию URL.

## Новостные источники

- [BBC News Русская служба](https://feeds.bbci.co.uk/russian/rss.xml)
- [ТАСС](https://tass.ru/rss/v2.xml)
- [Интерфакс](https://www.interfax.ru/rss)
- [Коммерсантъ](https://www.kommersant.ru/rss/news.xml)
- [РБК](https://rssexport.rbc.ru/rbcnews/news/30/full.rss)
- [Новости ООН](https://news.un.org/feed/subscribe/ru/news/all/rss.xml)
- [Deutsche Welle](https://rss.dw.com/rdf/rss-ru-all)

Приложение использует только заголовок, дату, ссылку и название источника.
Источник раскрывается после ответа. Ленты ограничиваются равным числом
кандидатов, чтобы одна редакция не определяла весь игровой набор.

## Структура

- `index.html` — семантическая разметка игры;
- `styles.css` — адаптивный интерфейс;
- `game-core.js` — чистая логика подготовки раундов;
- `script.js` — загрузка данных, состояние игры и события интерфейса;
- `tests/` — автоматические регрессионные тесты.
