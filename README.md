# Новость или фейк?

Статическая веб-игра на русском языке: игрок читает заголовок и выбирает, реальная это мировая новость или фейк. При каждом запуске реальные заголовки заново загружаются из BBC Russian RSS через открытый JSON-прокси rss2json, а фейки заново собираются из участников текущей повестки и правдоподобных новостных формулировок. Заранее прописанного набора заголовков и дневного кэша больше нет; до ответа описания и категории нейтральные и не раскрывают тип новости.

## Как открыть локально

```bash
python3 -m http.server 8000
```

После запуска откройте тестовую ссылку. Для генерации нового набора при каждом запуске нужен доступ браузера к интернету:

<http://127.0.0.1:8000/index.html>

## Быстрая проверка

```bash
node --check script.js
curl -I http://127.0.0.1:8000/index.html
```
