# Новость или фейк?

Статическая веб-игра на русском языке: игрок читает заголовок и выбирает, реальная это мировая новость или фейк.

## Как открыть локально

```bash
python3 -m http.server 8000
```

После запуска откройте тестовую ссылку:

<http://127.0.0.1:8000/index.html>

## Быстрая проверка

```bash
node --check script.js
curl -I http://127.0.0.1:8000/index.html
```
